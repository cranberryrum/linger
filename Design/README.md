# Linger logo

Approved concept: resting eye, with the original lowercase wordmark preserved in approved-logo.png.

The built-in image generator produced resting-eye-master.png from the approved concept using this prompt:

> Prepare the approved resting-eye logo in the reference as a production asset. Preserve the exact two-curve eye silhouette, proportions, asymmetry and tapered ends. Remove the wordmark and ivory background. Output ONLY the solid black eye symbol with genuinely transparent background, no texture, no shadow, no gradient. Center the mark and make it fill most of a wide canvas with a small even margin. Highest quality sharp antialiased edges for a macOS app icon master. Do not redesign the eye.

Run `swift scripts/generate-logo-assets.swift` from the repository to regenerate the template image scales and all macOS app icon sizes from the master. The app icon uses an ivory rounded tile; UI marks use template rendering for system appearance support.
